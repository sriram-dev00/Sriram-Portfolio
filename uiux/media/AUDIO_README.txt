AMBIENT AUDIO PLACEHOLDER
========================

Drop your looping ambient background track here:

  ambient.mp3   <- the file the sound toggle looks for

The engine references this path:
  media/ambient.mp3  (relative to D:/portfolio/index.html)

Accepted formats: .mp3  .ogg  .wav
Recommended: 60-300 second loop, fades well at both ends, < 3 MB.

Once the file is in place, click the speaker icon (bottom-right of the
site) to start playback. No code change needed.
